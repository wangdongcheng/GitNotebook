# 光与水的盛筵 ——曹家渡总领天神堂在逾越节夜间礼仪中为二十二位候洗者举行入门圣事
光与水的盛筵 ——曹家渡总领天神堂在逾越节夜间礼仪中为二十二位候洗者举行入门圣事

发表时间：24-04-05 来自：（曹家渡堂） 作者：  点击次数：188

3月30日，曹家渡圣弥额尔总领天神堂举行隆重的逾越节守夜礼，并在礼仪中为二十二位候洗者举行入门圣事，礼仪由本堂石广阔神父主礼。

礼仪开始前，司仪向信友们讲解了当日所举行的礼仪的意义——今夜整个教会在醒悟中等候着从死者中复活的主，并在入门圣事，即圣洗、坚振和圣体圣事中，与主相遇。这是以色列子民脱离奴役的一夜，也是基督战胜死亡的一夜，更是基督徒涤除罪污、重获新生的一夜，是我们从黑暗到光明、从死亡到永生的逾越之夜。

傍晚6点，烛光礼开始，教友们和候洗者们聚集在堂外广场上，石神父举起以圣火引燃象征复活基督的复活圣蜡，高唱“基督之光”，人群则手持从复活蜡上引燃的小蜡烛，同声回应“感谢天主”。

在三次“基督之光”的欢呼声和三次“感谢天主”的回应声中，整个堂区信友团体一起回到天主的圣殿之内，聆听基督复活的宣报，分享基督复活的喜讯。

基督——照世的真光

在聆听了基督复活的福音后，石神父为信友们阐述了逾越奥迹的深刻含义。石神父在讲道中表示：教会在礼仪中用象征的方式，以光和水来表达基督复活的奥迹。逾越庆典的第一个主题是光，复活的蜡烛预示着基督的光正在进入每个人心中；第二个主题则是水，因为水泉的活水是赋予生命的象征。藉着光和水，天主使我们明白人的生命与复活的基督之间的关系，因着领受了基督恩赐给我们的光明和活水，我们脱离死亡进入天主的生命，成为一个新受造物。

基督是照世真光，这真光照耀着每一个信友，也进入候洗者们的心灵。在经历了近一年的慕道之后，二十二位候洗者面对天主对他们爱的召唤，作出了自己的抉择，他们终于要在这逾越节的晚上领受教会的入门圣事。

候洗者们在代父母的陪伴下依次上前，主礼在他们的额上三次浇灌新祝福的洗礼用水，颂念洗礼经文。藉着圣洗圣事，每一个人都在基督内重生，加入教会，成为天主的子女。辅祭将象征新生的白色围巾递给代父母，并由他们为新教友披上，并递上从复活蜡烛上引燃新蜡烛，象征着他们在基督内的新生命的开始。

带来新生命的水

随后，新教友们领受了坚振圣事。藉此圣事，他们领受了圣神的洗礼，基督的圣神倾注在他们身上，赐给他们智慧和聪敏之神、超见和刚毅之神、明达和孝爱之神，敬畏之神，成为基督的勇兵。

在新教友额上傅以圣化圣油

在随后的圣祭礼中，新教友代表全体信友向天主奉献上礼品，同时也把自己作为祭品奉献给天主。他们也将第一次领受基督的圣体、宝血，与基督和祂的教会完全共融。

新教友代表奉献饼酒

“这是上主所安排的一天，我们应该为此鼓舞喜欢。”在这一夜，基督完成了牺牲，以祂自己的圣死摧毁了死亡，并以复活恢复了我们的生命；在这一夜，二十二位候洗者领受了入门圣事，加入了教会，成为天主的子民、我们的兄弟姊妹，正如在诸圣祷文中我们恳请终身童贞圣母玛利亚、总领天神、大圣若瑟和诸位圣人圣女向天主圣三所转求的，永生天主之子基督俯听并垂允了我们，并赐给了这二十二位特选者再生的恩宠。让我们衷心祝贺他们，也为他们祈祷，愿他们在今后的信仰生活中愈行愈健，积极活出天主子女的生命。

阿肋路亚！主真复活了！
