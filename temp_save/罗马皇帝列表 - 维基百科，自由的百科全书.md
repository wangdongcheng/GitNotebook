# 罗马皇帝列表 - 维基百科，自由的百科全书
这是[罗马帝国](https://zh.wikipedia.org/wiki/%E7%BE%85%E9%A6%AC%E5%B8%9D%E5%9C%8B "罗马帝国")历代[皇帝](https://zh.wikipedia.org/wiki/%E7%BD%97%E9%A9%AC%E7%9A%87%E5%B8%9D "罗马皇帝")一览表。[奥古斯都](https://zh.wikipedia.org/wiki/%E5%A5%A5%E5%8F%A4%E6%96%AF%E9%83%BD "奥古斯都")于前27年创[元首制](https://zh.wikipedia.org/wiki/%E5%85%83%E9%A6%96%E5%88%B6 "元首制")，开始了罗马帝国时期。罗马皇位的承继方式一般为养子承继制，但也有亲子承继的。罗马多次出现两帝共治，甚至[四帝共治](https://zh.wikipedia.org/wiki/%E5%9B%9B%E5%B8%9D%E5%85%B1%E6%B2%BB "四帝共治")。[戴克里先](https://zh.wikipedia.org/wiki/%E6%88%B4%E5%85%8B%E9%87%8C%E5%85%88 "戴克里先")创君主制，将皇帝进一步神化。

下表中粗体为合法君主，斜体为未受广泛承认的皇帝。
