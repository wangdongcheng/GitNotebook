# 中华文明是“唯一没有中断的文明”吗？——中国历史的第二个大泡泡-馋师-万维博客-万维读者网（电脑版）

一个泡泡吹破了，要接着吹下一个。五千年文明史，是靠不住的。至少，在世界范围内，在正式场合，是不敢这么说的。说了，会让人笑话的。换言之，五千年文明，也就在国内、关起门来讲讲，哄哄小粉红开心，而已。

下一个泡泡，就是“唯一没有中断”。

希腊文明中断了吗？没有。如果中断了，那希腊的城邦民主、帕特农神庙的大理石柱石、欧几里得几何、毕达哥拉斯学派、亚里士多德的学科分类、希腊悲剧、荷马史诗，从何谈起啊。显然，希腊文明是没有中断的。

如果，希腊文明没有中断，那古埃及文明，也就没有断。因为，无可否认，地中海文明是一个整体；无可否认，希腊是古埃及文明的继承者和发扬者；无可否认，公元前332年，埃及就有了一座希腊人建立的城市亚历山大城，还有地中海世界最大的图书馆，著名的古希腊科学家托勒密就是在这座图书馆，做研究的。

如此说来，希腊文明必定是得了古埃及的真传，虽然，不是全部。但要说古埃及文明中断了，恐怕也是不成立的。

两河流域的苏美尔文明中断了吗？苏美尔是发现于美索不达米亚文明中最早的文明体系之一，通过放射性碳十四断代测试，表明：苏美尔文明的开端可追溯至距今6000年前，在距今约4000年前结束，被闪族人建立的巴比伦所代替。

苏美尔人不在了，可是，他们的技术成就还是留下来了，如：轮、锯、鞣革、镯子、锤子、鞍、钉子、大头针、指环、铲子、釜、刀、长矛、箭、剑、胶、匕首、袋子、头盔、船、盔甲、箭筒、剑鞘、靴子、拖鞋、叉和酿酒。还有数学、历法、宗教等等。

看来，“四大文明”古国，中断的就是印度了。可是，我们也知道印度的佛教、种姓制度、阿拉伯数字（阿拉伯数字实际是印度人首创的），不管是好的，还是坏的，都还存在着。

这涉及一个基本问题，啥叫中断啊？啥叫文明中断？是说创造那一种文明的、那一群人断后了、不存在了吗？ 人、族群的延续，只能算是种族延续，不能叫文化和文明延续。比如，一个铁匠，他有儿子，还有孙子，可是，如果他的后代不再打铁了，那铁器这种技术，在他的家族就算是失传了。如果，铁匠把打铁的技术，传给了外人，那铁匠的技艺还在，并没有失传。

也就是说，族群延续和文明延续，是完全不同的两个概念。族群在，文化未必在；族群不在，文化和文明也未必就消亡了。比如，创造古希腊文明的那一族群，可能真的没有血亲留下来，可是，他们缔造的文明，却在世界范围内遍地开花。人民大会堂正立面那些高大的石柱，难道不是帕特农神庙传来的吗？

当今的汉人，是否是秦汉的后人，也未必；今天的文化，是否传自秦汉，也未必。所以，说唯一没有中断的文明，也不靠谱。作一个最悲观的假设，如果有一天中国这块地面上，没人了，也不能说中华文明就中断了。因为，朝鲜半岛、日本列岛，依然有中国文化的余脉。当然，不要自以为是地认为全是中国的啊。日本朝鲜，都发展了各自独特的文化。
